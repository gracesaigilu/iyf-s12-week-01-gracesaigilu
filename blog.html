My Journey into Web Development

Published on October 4, 2026 by Grace Kaisai

How I Started

My journey into web development started with learning the basics of HTML. At first, creating a webpage seemed difficult, but I gradually learned how HTML elements work together to create the structure of a website.

As I continued practicing, I learned how to create headings, paragraphs, links, navigation menus, sections, and footers. These skills helped me understand how websites are organized.

Learning Semantic HTML

One important lesson I learned was the importance of semantic HTML. Semantic elements such as header, nav, main, section, article, and footer make a webpage easier to understand and maintain.

Semantic HTML also helps improve accessibility because it gives browsers and assistive technologies a better understanding of the structure and purpose of a webpage.

Improving My Skills

I am continuing to improve my HTML and CSS skills by building projects and practicing different elements. I have also learned how to use GitHub to store my code and GitHub Pages to publish my website online.

Every project gives me an opportunity to learn something new. I plan to keep practicing and building more websites as I grow my web development skills.
